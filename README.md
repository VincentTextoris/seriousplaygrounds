# Serious Playgrounds — site statique (version épurée)

## Mise en ligne sur GitHub Pages

Le dossier contient directement `index.html` et `assets/`. Déposer **leur contenu à la racine du dépôt** (ou déposer le contenu du ZIP directement).

Dans GitHub : Settings → Pages → Deploy from a branch → main → /(root).

Le site ne nécessite ni compilation, ni dépendances, ni installation.

## Fichiers conservés

- `index.html` : page d’accueil
- `assets/styles.css` : styles responsive
- `assets/site.js` : navigation mobile
- `assets/images/` : uniquement les images utilisées dans le site

Les anciennes illustrations provisoires, doublons et fichiers sources d’archives ont été retirés. Les images sont optimisées pour la publication. Conserver les photos originales séparément en sauvegarde personnelle.

## À vérifier avant publication

- L’adresse e-mail `hello@seriousplaygrounds.com` dans les liens de contact.
- Les mentions légales et informations obligatoires selon votre situation.
- Les textes, références et images, ainsi que leurs autorisations d’utilisation.
- Le rendu sur mobile et navigateur après déploiement.

Typographie : Avenir Next / Avenir si disponible sur l’appareil, puis Helvetica Neue / Arial. Aucun fichier de police sous licence n’est distribué.

## Favicon
Le favicon est inclus à la racine (`favicon.png` et `favicon-16x16.png`) et référencé dans `index.html`.

## Remplacement d’un site GitHub Pages existant
Remplacer les fichiers de la branche et du dossier utilisés par Pages. Conserver le fichier `CNAME` existant si un domaine personnalisé est configuré, ainsi que les éventuels fichiers de configuration nécessaires au déploiement.
